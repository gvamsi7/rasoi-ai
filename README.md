# Rasoi AI

AI-powered Indian recipe discovery for households, bachelors, and working professionals.

## Features

- Ingredient list and voice input
- Breakfast, lunch, dinner, and quick bites
- High-protein, high-fiber, and healthy-fat filters
- Budget, cooking-time, and dietary filters
- AI recipe generation API route
- Recipe detail pages with SEO metadata and Recipe JSON-LD
- Shopping list and favorites foundations
- Responsive Next.js App Router UI

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local`:

```env
OPENAI_API_KEY=your_key_here
```

The AI endpoint is optional; the app includes local fallback recipes.
